## 차별화 포인트 (심사 항목별)
- 주제 타당성·창의성(15): 유동인구 대신 **와이파이 국적·방문유형**을 혼잡 센서로 — 반출 불가 제약을 발상으로 전환, 2026 현안(외국인 급증·준공영제·쏠림) 직결
- 필수 데이터 활용(20): 9종 실질 사용, 지표 정의·전처리 명문화
- 기술성·완성도(25): 도구호출 Agent + 규칙 폴백 + 반출 게이트 + 16개 테스트 + 실행 로그
- 편의성·실용성(25): 예시 버튼 클릭만으로 결과, 지도·차트·리포트, 외부망 없이도 동작
- 신뢰성·재현성(15): 모든 수치가 도구 로그·SQL/방법과 함께 저장, CLI 배치 재현, 합성 데이터 경고 강제

## 남은 작업 (우선순위)
1. 실데이터 CSV 확보 후 `data/raw/` 적재 → 컬럼 매핑·기간 확인 → 지표 임계값(15%, 1mm, 1.5km) 재조정
2. LLM 모드 실전 테스트(키 발급) + 시연 질문 12개 응답 품질 검토
3. 스크린샷·시연 영상, 결과 설명자료(문제정의·구조·기능·결과·검증·센터 활용)
4. (여유 시) 월간 관광지표 브리핑 탭, 노선-정류소 연결 데이터(3-05) 활용한 OD 분석
