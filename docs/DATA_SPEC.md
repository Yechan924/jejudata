## 2. 수집
- 제주데이터허브(jejudatahub.net) → 제주빅데이터센터 메뉴 → 해당 데이터 CSV 다운로드 → `data/raw/` 복사 → `python scripts/check_data.py`로 점검. 단계별 절차·대안 데이터·센터 방문 요령은 `docs/DATA_ACQUISITION.md`.
- 파일명은 데이터명(한글)·코드·영문키(`wifi_ap_usage` 등) 어느 것으로 시작해도 자동 인식. 여러 기간 파일은 `data/raw/wifi_ap_usage/*.csv` 처럼 폴더에 모아도 됨.

- 날씨(5-02·5-01)는 허브에 없다 → `python scripts/fetch_weather.py` 로 받는다. (A) 기상청 기상자료개방포털(data.kma.go.kr) 종관기상관측(ASOS) 일자료 CSV를 `--kma-csv` 로 변환(관측값, 권장; 변환 없이 `data/raw/`에 넣어도 별칭으로 읽힘), (B) `--open-meteo` 로 Open-Meteo 과거 기상 API(키 없음, CC BY 4.0, ERA5 재분석 격자값), (C) `--kma-api` 로 기상청 API허브(인증키). 관측소는 제주(184)·고산(185)·성산(188)·서귀포(189) 4개이며 5-01이 없으면 `config/weather_stations_jeju.csv`(기상청 지점 정보)를 쓴다. 무강수일의 빈칸은 0mm로 둔다.

## 3. 전처리 (`jeju_agent/data/loader.py`)
1. 인코딩 자동 판별(utf-8-sig → cp949 → euc-kr).
2. 헤더 표준화: ① 명세서의 컬럼명(영문)·컬럼명(한글) 정확 일치(공백·괄호 무시) → ② 비는 컬럼은 `config/column_aliases.yaml`의 별칭 포함 매칭(정류장명·승차인원수·기준일자 등) → ③ 그래도 없는 컬럼은 데이터셋별 기본값(예: 3-04 변형 자료의 get_on_off_type=승차)으로 채우고 적재 상태(provenance)와 답변 한계에 기록. CSV/TSV/XLSX, 쉼표·탭·세미콜론 구분자, 날짜 표기(2025-03-01·2025/3/1·20250301) 통일.
3. 타입 캐스팅: 명세서 INT/BIGINT/DOUBLE + 위경도·user_count 등 STRING으로 표기된 숫자 컬럼을 숫자로.
4. 파생 컬럼: `date`(YYYY-MM-DD), `ym`, `weekday`(0=월), `dow`(월~일), `is_weekend`, `hour`.
5. 중복 정보성 테이블(노선·정류소 정보)은 ID 기준 `drop_duplicates`로 최신 1행만 사용.
6. 결측·형식 오류 값은 NaN 처리(오류로 중단하지 않음).
7. 테이블 간 이름 연결(허브 API 집계본): 3-04 정류소명→3-03 ID, 4-05 장소명→4-01 좌표·카테고리를 ① 정확 일치 → ② 정규화 키(공백·괄호·`[동/서/남/북]`·`#2-2`·` 1-2` 같은 꼬리표 무시) → ③ 유일한 포함 관계(4자 이상) → ④ 장소명 속 정류소ID·정류소명으로 3-03 좌표 순으로 잇는다. 3-04에서 정류소명이 빈 행은 같은 원본ID가 다른 날짜에 가진 이름으로 채운다. 매핑률과 미연결 이름 상위 15개는 provenance에 남겨 `check_data.py`·자동 점검에 표시한다.
8. 실데이터와 기간이 겹치지 않는 합성 데이터(날씨·4-06)는 적재하지 않는다(합성 강수량이 실데이터에 섞이는 것을 막기 위함). 해당 기능은 비활성으로 표시되고 수집 방법을 안내한다.

## 4. 분석 흐름과 지표 정의
| 도구 | 정의 |
|---|---|
| 혼잡지수 | `장소·일 고유 user_id 수 ÷ 분석기간 평일 중앙값`. 1.0=평소 평일 수준 |
| 관광/외국인 비중 | visit_type='관광' / nationality≠'대한민국' 이용자 ÷ 전체 |
| 정류소 일평균 승차 | get_on_off_type='승차' user_count 합 ÷ 일수 |
| 교통약자 비중 | (경로+어린이+장애+유공) ÷ 전체 승차 |
| 노선 효율 | 일평균 승차 ÷ 노선거리(km); 저이용 시간대 = 시간대 승차 < 피크의 15% (05~23시) |
| 강우 효과 | 가장 가까운 관측소 일강수량 ≥ 1mm를 강우일로 보고 `강우일 평균 ÷ 비강우일 평균 − 1` (평일/주말 분리) |
| 관광지 접근 | 와이파이 장소 좌표 기준 반경 1.5km(haversine) 내 정류소의 승차·피크 시간 |

## 5. 반출 게이트 (`jeju_agent/gate.py`, `config/export_rules.yaml`)
LLM·화면·리포트로 나가는 모든 표는 ① 식별자 컬럼 제거 ② 500행 상한 ③ 10명 미만 인원 셀 `<10` 마스킹(센터 반출 정책 2026.09.01 단순집계 기준, `EXPORT_MIN_CELL_COUNT`로 조정) ④ 원본 행 조회 차단(run_sql은 집계 쿼리만) 을 거친다. 비반출 데이터를 추가하더라도 같은 경로로만 결과가 나간다.

## 6. 외부 데이터·오픈소스
- 외부 데이터: 없음 (합성 데이터는 명세서 구조만 참고한 자체 생성물). 집에서 수집하는 허브 공개 API 6종도 제공처가 제주빅데이터센터이며 명세서 데이터의 집계본이다.
- 오픈소스: pandas, numpy, DuckDB, Streamlit, Plotly, pydeck, PyYAML, python-dotenv, requests, pytest.
- 외부 API: LLM(Anthropic / OpenAI, 선택). 원본 행은 전송하지 않으며 게이트 통과 집계표(최대 40행 텍스트)만 전송.
